# 食物紀錄（豆包版本）

每日食物紀錄 + 期間統計 + 就醫報告。純前端三個檔案（`index.html`＋`styles.css`＋`app.js`），部署在 GitHub Pages，資料存在使用者自己的瀏覽器。

**線上版：https://lemon74088.github.io/food-log/**（手機直接用這個網址，加入主畫面就是 App）
設計方向試玩：https://lemon74088.github.io/food-log/design-demos/switch.html （D 手帳／E 雜誌／F 玻璃 三版即時切換）

> 這個 repo（`food-log`）就是正式版，只此一個網址。
> `food-diary` 是另一個 repo（你自己的「我的食物日記」版本08），跟這裡的資料**完全不相通**，不要兩邊輪流記。

## 已做的功能

- **今天**：一句話快速記錄、自動判定餐別（早餐／午餐／點心／晚餐／宵夜）、時間戳記
- **補記**：用 ‹ › 換日；或在日曆頁點日期，下方直接顯示那天紀錄並可就地補記
- **常用**：依最近 30 天頻率自動產生「最近常吃」快捷詞
- **照片**：每筆可附 1 張，自動壓到長邊 800px、JPEG 品質 0.72（約 100 KB）
  - 只加照片、不打字也能記錄：卡片顯示「只有照片，還沒有文字」，照片放大成 96px，之後可用「編輯」補文字
  - 沒有文字的照片紀錄不會被算進食物詞頻與多樣性
- **症狀**：每筆可標脹氣／腹瀉／胃痛／疲倦／過敏／頭暈，報告可做「食物 → 症狀」對照
- **編輯**：改時間、改餐別、改內容、加備註
- **小貓打卡**：今天頁上方三隻小貓（橘子／芝麻／布丁），按「今天打卡」累積連續天數與點心；紀錄存在 `localStorage` 的 `fl-pets-v1`，跟食物資料分開，清空食物紀錄不會清寵物；寵物進度會跟著備份 JSON 的 `pets.days` 一起匯出／匯入
- **成就徽章**：兩系列共 9 顆——打卡累計 1／3／7／14／30 天（初次相遇→最強羈絆，橘色六角）與紀錄累計 1／30／100／365 筆（第一筆紀錄→一整年，紫色六角）。跨過門檻時跳出解鎖動畫（外框一筆畫出 → 內部填色 → 星星旋轉縮小蓋章 → 四周光芒射出 → 文字依序浮現），點畫面或按 Esc 關閉；統計頁底部有徽章牆，已解鎖實線、未解鎖虛線。純 CSS 關鍵影格，沒有外部動畫函式庫，系統設「減少動態效果」時顯示靜態版
- **下載單檔案**：設定頁可按「下載單檔案」把 HTML／CSS／JS／小貓圖打包成一個 `index.html`，方便放到任何靜態空間（打包出的檔案會自動隱藏這個按鈕）
- **日曆**：一眼看出哪幾天有記、哪幾天缺
- **統計**：最近 7／30 天、本月、上月、自訂區間
  - 記錄完整度（記了幾天、缺哪幾天）
  - 紀錄筆數、食物多樣性、有症狀的餐數
  - 最常出現排行（簡易詞頻：以「、，空白」切詞）
  - 24 小時進食分布、第一餐／最後一餐平均時間、進食窗口
- **報告**：選期間 → 勾欄位（時間／照片／症狀／備註）→ 預覽 → 列印成 PDF
- **資料**：匯出／匯入 JSON、軟刪除可復原（6 秒內按「復原」）、儲存空間估算

## 資料存在哪裡

存在瀏覽器的 **IndexedDB**（資料庫名稱 `foodlog-db`，資料表 `entries`），不會上傳到任何地方。

三個會弄丟資料的情況：

1. **換網址**（改 repo 名、加自訂網域）→ 瀏覽器把新網址當另一個網站，舊資料讀不到
2. **換裝置或換瀏覽器** → 各裝置各記各的，不會同步
3. **清瀏覽器資料** → 直接消失
4. （手機端）長時間沒開，系統可能回收儲存空間；用通訊軟體內建瀏覽器開，資料常不保留

所以：**開始記真實資料前先鎖定網址**，並定期在「設定 → 匯出備份」存一份 JSON。設定頁會顯示上次備份日期。

## 試玩（示範模式）

打開 `index.html?demo=1`（或部署後在網址後面加 `?demo=1`）會進入示範模式：

- 自動載入 6 天、11 筆範例紀錄，所有統計、日曆、報告都有內容
- **完全可操作**：可以新增、編輯、刪除、匯出、列印
- **不會存檔**：資料只在記憶體裡，重新整理就還原，也完全不會動到你真正的紀錄
- 頁面上方會顯示橘色「示範模式」提示條

正式使用時打開 `index.html`（不帶參數）即可，兩者是同一個檔案。

## 部署到 GitHub Pages

### 方法 A：網頁操作（不用裝 git）

1. 在 GitHub 建一個新的 repository（建議名稱 `food-log`，公開）
2. 進入 repo → **Add file → Upload files** → 把 `index.html`、`styles.css`、`app.js` 三個檔案一起拖上去 → Commit
3. **Settings → Pages** → Source 選 `Deploy from a branch` → Branch 選 `main`、資料夾選 `/ (root)` → Save
4. 等 1–2 分鐘，網址會是：

```
https://你的帳號.github.io/food-log/
```

### 方法 B：命令列

```bash
cd "D:\github(app 製作)\食物紀錄 (豆包版本)"
git init
git add index.html README.md
git commit -m "食物紀錄 v0.1"
git branch -M main
git remote add origin https://github.com/你的帳號/food-log.git
git push -u origin main
```

推上去之後，一樣到 **Settings → Pages** 開啟。

### 手機上使用

用瀏覽器打開上面那個網址即可。iPhone 可用 Safari 的「分享 → 加入主畫面」，Android Chrome 選「安裝應用程式」，用起來就像 App。

## 網址一旦定了就不要再改

`https://帳號.github.io/food-log/` 這個來源（origin）就是資料的鑰匙。之後若想接自訂網域，得先匯出 JSON，換網址後再匯入。建議就固定用 Pages 網址。

```

README.md         本說明
design-demos/     六個外觀方向 + switch.html 三版即時切換（示範資料）

```

沒有 build 步驟、沒有 npm、沒有外部 CDN（唯一外部資源是字體 CSS），改完存檔推上去就是新版。

字體：`index.html` 向 `https://miaoda.feishu.cn/fonts/css2` 要 Noto Sans TC。那個端點實測只回 Noto Sans TC 400，Nunito 不會載入，數字會退回系統字體；不影響功能。

## 介面質感（v0.4 視覺更新）

- 磨砂玻璃外殼：`.app` 半透明底色 + `backdrop-filter: blur(22px) saturate(1.35)`，內層白色高光，讓背後的暖色光斑透上來；列印時自動還原白底。
- 懸浮感：底部導覽列更透（`blur(26px)`）＋白色描邊＋浮起陰影；桌機在 `.tile/.bdg/.cat/.card` 上滑時上浮 2–3px。
- 邊框聚光（Motion Library `fx/301`）：游標在統計磚與徽章牆上移動，每張卡依游標相對位置畫柔和內光暈、邊框亮成卡片自己的主題色；觸控裝置按下時同樣亮起，700ms 後淡出。
- 頁籤彈跳（參考 `fx/200` 的節奏，去掉 360° 翻轉）：點頁籤時「壓扁蓄力 → 跳起 → 落地回彈」，圖示同步輕彈。
- 以上動效在系統「減少動態」設定下自動關閉。
## 報告改為直接下載 PDF（v0.4.1）

之前「列印 / 存成 PDF」是呼叫瀏覽器列印對話框（`window.print()`）。在某些環境會叫不出來、或叫出來是空白：手機 App 內建瀏覽器、部分 Android WebView、以及被系統擋掉的列印服務。

現在改成純前端自繪：按「下載 PDF 檔」→ app.js 直接用 Canvas 把 A4 版型排好（頁首、期間、摘要、逐日明細、照片、症狀、備註、頁尾頁碼）→ 打包成真正的 PDF 檔下載。不需要列印對話框、不需要任何外部函式庫、不連網。

- 分頁規則：A4 直式，日期標題不與第一筆紀錄拆開；續頁自動加「期間報告（續）」頁首與頁碼。
- 檔案：`食物紀錄_YYYYMMDD-YYYYMMDD.pdf`；手機若支援分享檔案會走系統分享（可存到「檔案」App），否則直接下載。
- 仍保留列印：說明文字旁的「改用列印對話框」可走原本的 `window.print()`。
- 內容依報告頁的四個勾選項（時間／照片／症狀／備註）決定要不要出現。
